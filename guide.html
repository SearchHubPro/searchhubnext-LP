はじめに

最初の設定

ここだけは順番どおりにお願いします。10分ほどです。

1　アプリを開く

契約完了メールに入っているURLを開きます。ソフトのインストールはありません。ブラウザで開くだけです。

  • PC版… Chromeで開いて、ブックマークに入れておいてください。
  • スマホ版… iPhoneはSafariで開いて、共有ボタン →「ホーム画面に追加」。アプリのように使えます。Androidは Chrome のメニュー →「ホーム画面に追加」です。

2　⚙️ アプリ基本設定に3つ入れる

右上の歯車から「アプリ基本設定」を開いて、3つとも埋めてください。3つそろわないと動きません。

欄入れるもの
ライセンスキー契約完了メールに書いてあるキー。そのまま貼り付け。
Keepa APIキーKeepaのサイト → Data → API から取得したキー。
AmazonセラーIDセラーセントラルの出品者ID。A から始まる英数字です。

入れたら「設定を保存」。この画面には「プラン変更・解約・お支払い状況の確認はこちら」のリンクもあります。プランの変更や解約は、すべてここからです。

ライセンスキーは契約完了メールにしか載っていません。メールは消さずに置いておいてください。パソコンとスマホの両方で使う場合は、それぞれに同じキーを入れます。台数の制限はありません。

3　⚙️ 情報設定を埋める

ダッシュボード →「情報設定」。仕入先リストとコンディション別の商品説明が入っています。はじめは代表的な10サイトと、商品説明の見本が入っています。そのままでも使えますし、自分の言い回しに書き換えても構いません。くわしくはこちら。

4　拡張機能を入れるNEXT極

契約完了メールのリンクから、Chromeウェブストアで追加します。

  • SearchHubNEXT（ウォッチャー）… NEXT・極
  • SearchHub SniperNEXT（スナイパー）… 極のみ

追加したら、拡張機能の設定画面を開いて同じライセンスキーを貼り付けてください。ここを忘れると、巡回が1件も動きません。

5　仕入れリストに商品を入れて、URL同期を押すNEXT極

巡回は「仕入れリストに入っている商品」をさがしにいきます。まずは追いたい商品を何点か入れてください。Amazonリサーチの「📋 仕入れリストへ追加」から入れられます。

入れたら「URL同期」を押してください。検索URLが作られるのは毎晩2時なので、その時刻が来るまではURLが1本もありません。この状態で巡回しても何も起きません。初日に「動かへん」となるのは、ほとんどこれです。巡回進捗パネルの「URL同期」を押せば、その場で作られます。

6　巡回パソコンの設定NEXT極

毎日ほったらかしで回すための設定です。契約完了メールのリンクから設定一式をダウンロードして、中の手順書のとおりに進めてください。15分ほどです。概要はこちら。

ライトの方は、拡張機能も巡回パソコンの設定も必要ありません。ここまでで完了です。

出品中の商品を一覧にして、ライバルの価格と今の値段で売れたときの手残りを並べて見る画面です。

「この商品だけ詳細確認」ボタンが出ているとき

低トークンモードがオンのとき、裏の処理はKeepaに問い合わせません。そのため、まだ値段を取っていない商品には紫の「この商品だけ詳細確認」ボタンが出ます。気になる商品だけ押してください。その1件だけKeepaに聞きにいきます。くわしくはこちら。

Manager

情報設定全プラン

アプリ全体で使う「決まり文句」をここにまとめます。最初にここを埋めておくと、あとの入力がぐっと楽になります。

仕入れ先リスト

販売管理で仕入先を選ぶときの候補になります。はじめは代表的な10サイト（メルカリ／ヤフーフリマ／ヤフオク／オフモール／セカストオンライン／ラクマ／駿河屋／ヤフショ／au PAY／トレファク）が入っています。

店舗仕入れをされる方は、行き先の店名を1行ずつ足しておいてください。「ハードオフ◯◯店」のように書いておくと、あとで月別仕入情報を見たときに、どの店が当たりだったかが分かります。

コンディション別の商品説明

「ほぼ新品」「非常に良い」「良い」「可」の4つに、それぞれ定型文を登録します。ここで登録した文章が、一括商品登録の「提供条件に関する注記」に自動で入ります。

はじめは見本の文章が入っています。そのままでも使えますが、自分の言葉に書き換えたほうがクレームは減ります。とくに「可」は、どこまで許容してもらうかをはっきり書いておいてください。

🪙 低トークンモード

Keepaのトークンを節約する設定です。くわしくはこちら。

💳 カード支払い設定

仕入れに使うカードを最大5枚まで登録できます。締め日を入れておくと、いつ払うことになるかの見通しが立てやすくなります。

全部入れたら、いちばん下の「この内容で保存」を押してください。保存を押さないと反映されません。

Researcher

仕入れリストNEXT極

これから追う商品の一覧です。ここに入っている商品を、巡回が毎日さがしにいきます。

検索キーワードが一番大事です

行の「編集」を押すと、「検索キーワード(手動調整OK)」という欄があります。巡回はこの言葉でフリマを検索します。

自分で登録した商品は、型番だけになっていることがあります。たとえば HD-LX4.0U3D だけだと、まったく別のゴミ商品まで拾ってきます。「バッファロー HD-LX4.0U3D」のようにメーカー名を足してください。ここを直すだけで、拾ってくる商品の質がはっきり変わります。

逆に、言葉を足しすぎると1件も引っかからなくなります。メーカー名＋型番くらいがちょうどいいです。色や容量まで入れると、出品者が書いていない場合に外れます。

その他の操作

ボタンすること
データを取得一覧を最新にします。
編集検索キーワード・仕入日・仕入値・メモなどを直します。
削除追うのをやめます。巡回の対象から外れます。

一覧には平均売価・中古最安・ランクも出ています。精査日が古い商品は相場が変わっている可能性があるので、たまに見直してください。

Researcher

セラー一時保管所 / セラーリスト / セラーグループ進捗NEXT極

自動リサーチの心臓部です。いい商品を扱っているセラーを見つけて、そのセラーの品揃えを丸ごと調べにいくという考え方で動いています。

画面役割
セラー一時保管所システムが見つけてきたセラーの候補が入ります。ここで承認か見送りを選びます。
セラーリスト承認したセラーの一覧。ここに入ったセラーの品揃えを、順番に調べていきます。
セラーグループ進捗今どのグループまで調べ終わったか。何人中何人まで進んだかが分かります。

承認するときの目安

一時保管所には、良いセラーも普通のセラーも混ざって入ってきます。全部承認しないでください。数が増えるほど1周にかかる時間が延びて、肝心のセラーを調べる回数が減ります。

自分が扱いたいジャンルを中心に扱っているセラーだけを承認して、あとは見送りにするのがコツです。見送っても、また出てくることがあります。

Researcher

リサーチャー設定NEXT極

自動リサーチの「合格ライン」を決める画面です。4つのタブに分かれています。ここの数字で、拾ってくる商品の量と質が決まります。

⚙️ 各種設定

項目意味
💰 目標利益率 (%)この利益率に届かない商品は候補に出しません。高くすると数が減り、低くすると増えます。
💴 仕入値基準設定巡回の検索URLに使う「いくらまでなら買うか」の計算のしかたです。【A】90日平均から出すと【B】最安値から出すのどちらか。Aのほうが強気、Bのほうが堅めになります。
🚫 除外ワード検索URLの末尾に付けて、いらない商品をはじきます。「ジャンク」「部品取り」などを入れておくと効きます。
🚫 除外ブランド扱わないブランドを改行区切りで。出品制限がかかっているブランドを入れておくと無駄が減ります。
🔁 連続実行URL数一度に何件のURLを続けて回すか。増やすと速いですが、パソコンとサイト側の負担も上がります。

対象は メルカリ／ヤフーフリマ／ヤフオク／オフモール／セカストオンライン／ラクマ／駿河屋／ヤフショ／au PAY／トレファク の10サイトです。

やること

  • 画面の上でサイトを選びます。
  • そのサイトの検索URLが並んでいます。仕入れリストに商品を入れると、ここに自動で作られます。
  • 拡張機能を入れたパソコンでNEXTのページを開いておけば、あとは自動で回ります。
検索URLは自動で作られます。もとになるのは、仕入れリストの「検索キーワード」と、リサーチャー設定の仕入値基準・除外ワードです。拾ってくる商品がおかしいときは、URLをいじるより先に検索キーワードを見直してください。
はじめて使うときは「URL同期」を押してください。
検索URLが作られるのは毎晩2時です。仕入れリストに商品を入れても、その時刻が来るまではURLが1本もありません。この状態で巡回しても、回るものが無いので何も起きません。「初日は動かんかった」となるのは、ほとんどこれです。
巡回進捗パネルの「URL同期」を押すと、その場で作られます。押したあとにウォッチャーの画面を開いて、URLが並んでいれば準備完了です。

回さないサイトは、拡張機能の設定でチェックを外せます。使わないサイトを外すと、1周が速くなります。

スナイパー極

メルカリ・ヤフーフリマ・オフモールの3サイトを短い間隔で見張って、条件に合う出品が出たら即座に知らせるのがスナイパーです。ウォッチャーより狭く、そのぶん速いです。

安く出た中古は、出品から数分で消えます。ウォッチャーの1周を待っていると間に合わないので、その3サイトだけを集中して見にいきます。

オプションで調整できること

スナイパー拡張の設定画面（オプション）で、動きを細かく変えられます。

項目意味
⏳ 判定開始までの待ち時間（秒）ページを開いてから中身を見るまでの待ち時間。短すぎると、まだ表示が終わっていないので「なし」と誤判定します。
リトライ回数中身が読めなかったときに、何回やり直すか。
強制タイムアウト（秒）ここまで待って駄目なら、あきらめて次に行きます。
「待ち時間 ＋ リトライ回数 × 2秒」が強制タイムアウトより短くなるようにしてください。ここが逆転していると、リトライの途中で打ち切られて、いつまでも拾えません。

商品が出ているのに「なし」ばかりになるときは、まず待ち時間を1〜2秒増やしてください。ほとんどの場合これで直ります。

設定一式に入っているもの

セット向いている使い方
A 通し運転1台で全部やる方、または巡回専用機でウォッチャーとスナイパーを両方回す方。一日中動くので取りこぼしが少ないです。

プランの変更と解約

手続きはすべて、アプリの⚙️ アプリ基本設定にある「プラン変更・解約・お支払い状況の確認はこちら」のリンクからです。こちらへご連絡いただく必要はありません。

プランを上げたとき

  • ライセンスキーは変わりません。入れ直しは不要です。
  • 新しく使えるようになった機能を書いたメールが届きます。
  • 拡張機能が必要になる場合は、そのメールにリンクが入っています（NEXTなら ウォッチャー、極なら さらに スナイパー）。追加したら、今お使いのライセンスキーをそのまま貼り付けてください。
  • アプリを開き直すと、それまで押せなかったボタンが使えるようになります。

プランを下げたとき

キーはそのままです。使えなくなる機能を書いたメールが届きます。これまでのデータはすべて残ります。販売管理も月別も経費も、そのままです。あとで上のプランに戻したときは、続きから使えます。

下のプランで動かなくなった拡張機能は、入れたままでも構いません。外していただいても差し支えありません。

解約したとき

解約されても、お支払い済みの請求期間の末日までは、そのままご利用いただけます。期間が終わるとライセンスキーが無効になり、アプリと拡張機能が使えなくなります。

巡回パソコンの設定（タスクスケジューラのタスク）は、消さずに残しておいて構いません。

もう一度契約したとき

以前のデータはそのまま見られます。販売管理・月別・経費・仕入れリスト、すべて残っています。
ただしライセンスキーは新しいものが発行されます。再契約のメールに載っているキーを、アプリと拡張機能の両方に入れ直してください。前のキーはもう使えません。
プラン変更や解約のメールが届かないときは、迷惑メールフォルダを見てください。ここに入っていることが多いです。見つけたら「迷惑メールではない」に設定しておくと、次から届くようになります。

よくあるつまづき

画面を開いても何も出てきません

⚙️ アプリ基本設定の3つ（ライセンスキー・Keepa APIキー・AmazonセラーID）が全部入っているか確かめてください。1つでも空だと動きません。

巡回がまったく動きません

順に見てください。①ウォッチャーの画面に検索URLが並んでいるか（1本も無ければ「URL同期」を押してください。はじめて使う日はこれが原因です）②拡張機能にライセンスキーを入れたか ③Chromeで NEXTのページを開いているか ④拡張機能の設定で、そのサイトのチェックが入っているか ⑤パソコンが起きているか。

商品が出ているのに「なし」と判定されます

拡張機能の判定待ち時間が短すぎます。オプションで1〜2秒増やしてください。ページの表示が終わる前に見にいくと、何も無いように見えてしまいます。

巡回が関係ない商品ばかり拾ってきます

仕入れリストの「検索キーワード」が型番だけになっていませんか。メーカー名を足してください。くわしくはこちら。

リサーチの候補が1件も出てきません

リサーチャー設定の条件が厳しすぎる可能性があります。目標利益率を少し下げてみてください。あわせて実行ログを見て、そもそも作業が走っているかも確かめてください。

候補が多すぎて見きれません

目標利益率を上げるか、「👥 飽和商品削除」の人数を小さくしてください。承認しているセラーが多すぎる場合もあります。

Keepaのトークンがすぐ無くなります

低トークンモードを試してください。あわせて実行予約で使っていない作業をオフに、バッチ設定の件数を小さくしてください。

ボタンを押したら「◯◯プランでご利用いただけます」と出ました

そのプランでは使えない機能です。⚙️ アプリ基本設定の「プラン変更・解約・お支払い状況の確認はこちら」からプランを上げれば、そのまま使えるようになります。データは何も消えません。

パソコンとスマホの両方で使えますか

使えます。同じライセンスキーを両方に入れてください。データは同じものを見ているので、外で入れた仕入れが家のパソコンにも出てきます。

ライセンスキーを無くしました

契約完了メールを探してください。見つからない場合はお問い合わせください。再発行の手続きをご案内します。

プランを下げたらデータは消えますか

消えません。販売管理・月別・経費のデータはそのまま残ります。上のプランに戻したときは、続きから使えます。
